# Reporting a security problem

**Not in an issue.** Issues here are public, and a public report is a working exploit
for everyone who reads it before it is fixed.

Mail **hallo@square-management.nl** instead. It is a dedicated address, never a personal one.

## What to include

- What the problem is, and what someone could do with it.
- The steps to reach it, in enough detail to get there without guessing.
- The Stapel version, from Settings then About, and the Android version.
- Whether anything on the device is exposed by it: cards, codes, or location.

**Never send a real loyalty card number.** Say which brand and describe the shape of the
code. A report is not worth less for leaving the number out.

## What happens next

Stapel is one person's project with no team and no on-call rota, so there is no
response-time promise worth making. What is promised: a reply, an honest answer about
whether it is being fixed, and credit in the release notes if you want it.

A fix ships in the next release. There is no separate advisory feed.

## Scope

This repository holds no code. It is where reports about the Stapel Android app, its
shop data and its brand catalogue are collected. The application source is not published.
