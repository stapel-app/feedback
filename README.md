# Stapel — meldingen en verzoeken / reports and requests

[Nederlands](#nederlands) · [English](#english)

**Er staat hier geen code.** Dit is de plek waar meldingen over de Stapel-app binnenkomen:
een keten die ontbreekt, een winkel die niet klopt, of iets in de app dat stukgaat.
De broncode van de app is niet gepubliceerd.

**No code lives here.** This is where reports about the Stapel app are collected: a chain
that is missing, a shop that is wrong, or something in the app that breaks. The
application source is not published.

---

## Nederlands

### Wat hier hoort

| Melding | Waar |
|---|---|
| Een keten die Stapel niet kent | [Nieuw issue](https://github.com/stapel-app/feedback/issues/new?template=missing_brand.yml) |
| Een winkel die ontbreekt, verhuisd of dicht is | Liever direct in [OpenStreetMap](https://www.openstreetmap.org/edit) |
| Iets in de app werkt niet | [Nieuw issue](https://github.com/stapel-app/feedback/issues/new?template=bug_report.yml) |
| Een beveiligingsprobleem | **Nooit in een issue.** Zie [SECURITY.md](SECURITY.md) |

Winkellocaties komen uit OpenStreetMap. Daar corrigeren helpt iedereen die die kaart
gebruikt, blijvend, en het komt bij de volgende herbouw vanzelf in Stapel terecht.
De merkencatalogus is wél van ons: daar is geen bovenliggende bron voor, dus een goede
merkmelding is het nuttigste wat je kunt sturen.

### Liever mailen

**hallo@square-management.nl**. Een apart adres, nooit een persoonlijk. Een issue blijft
handiger, want daar kun je meelezen, maar niemand hoeft een account op een codesite te
maken om een winkeladres door te geven.

### Wat er verder open staat

- De winkeldata die de app downloadt: [stapel-app/store-data](https://github.com/stapel-app/store-data), afgeleid van OpenStreetMap, onder de ODbL.
- De website en de releasenotities: [stapel-298.pages.dev](https://stapel-298.pages.dev/)

### Ben je een keten?

Wil je je naam, kleur of logo niet in de app zien, dan halen we het weg. Eén bericht is
genoeg. Wil je juist wél je echte logo getoond zien, dan vraagt dat schriftelijke
toestemming, per stuk vastgelegd met bron en licentie.

## English

### What belongs here

| Report | Where |
|---|---|
| A chain Stapel has never heard of | [New issue](https://github.com/stapel-app/feedback/issues/new?template=missing_brand.yml) |
| A shop that is missing, moved or closed | Preferably straight into [OpenStreetMap](https://www.openstreetmap.org/edit) |
| Something in the app does not work | [New issue](https://github.com/stapel-app/feedback/issues/new?template=bug_report.yml) |
| A security problem | **Never in an issue.** See [SECURITY.md](SECURITY.md) |

Shop locations come from OpenStreetMap. Correcting them there helps everyone using that
map, permanently, and it arrives back in Stapel on the next rebuild. The brand catalogue
is ours, though: there is no upstream for it, so a good brand report is the most useful
thing you can send.

### Rather send mail

**hallo@square-management.nl**. A dedicated address, never a personal one. An issue is
still handier because you can follow it, but nobody should need an account on a code site
to pass on a shop address.

### What else is open

- The shop data the app downloads: [stapel-app/store-data](https://github.com/stapel-app/store-data), derived from OpenStreetMap, under the ODbL.
- The website and the release notes: [stapel-298.pages.dev](https://stapel-298.pages.dev/)

### Are you a chain?

If you would rather not see your name, colour or logo in the app, it comes out. One
message is enough. If you would like your real logo shown instead, that needs written
permission, recorded per logo with its source and licence.
